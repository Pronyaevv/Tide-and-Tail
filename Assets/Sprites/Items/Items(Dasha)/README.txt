TIDE & TAIL — 32px sprite pack

Folders:
- items_32x32/: individual inventory icons, each exactly 32x32 px, transparent PNG.
- large_assets/: larger tools/boats/motors; dimensions are multiples of 32 px.
- sprite_sheets/: combined atlases, contact sheet, and manifest.

Aseprite:
1. Open the individual PNG or atlas.
2. Keep the canvas size unchanged when importing.
3. For larger assets, use the documented dimensions in manifest.json.
4. If editing/resizing, use Nearest Neighbor to preserve hard pixel edges.

Production note:
These are first-pass extracted assets from the generated concept sheet, not hand-redrawn native-resolution sprites. Inspect the alpha edges and simplify details where necessary before final game integration.
